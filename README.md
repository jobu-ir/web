# وب‌سایت عمومی جاب‌یو (مخصوص مخزن GitHub Pages)

این پوشه حاوی کدهای مستقل وب‌سایت عمومی برای اتصال مستقیم کاربران اینستاگرام به آگهی‌های استخدام است.

## نحوه استقرار در گیت‌هاب پیجیز (GitHub Pages):
1. محتویات این پوشه (`index.html` و `data.json`) را در مخزن عمومی خود در گیت‌هاب قرار دهید.
2. در تنظیمات ریپازیتوری وارد بخش **Settings > Pages** شوید و شاخه `main` را انتخاب کنید.
3. سایت شما بلافاصله روی آدرسی مانند `https://your-username.github.io/repo-name/` فعال می‌شود.

## نحوه به‌روزرسانی آگهی‌ها:
با هر بار زدن دکمه **«پایش زنده»** در استودیو، فایل `site/data.json` به طور خودکار بازنویسی و با اطلاعات جدید جایگزین می‌شود. کافیست فایل `data.json` جدید را در گیت کامیت و پوش کنید (`git commit -am "Update jobs data" && git push`).
